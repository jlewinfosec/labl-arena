# Game-day ready checklist (v0.5.0)

Run through this the night before the first real event on the app, and the morning of.

## The night before
- [ ] Tablet on the charger; Bluetooth speaker charged.
- [ ] Open LABL from the home-screen icon (not a Chrome tab). Board Member panel › Settings: version reads 0.5.0 and Storage says **Protected**.
- [ ] Settings › Backup › **Send to Google Drive** once, so you know the share sheet works on this tablet.
- [ ] Roster tab: every regular is on it; tap the age chips (Youth / Teen / Adult).
- [ ] Settings › Opening talk: reads the way you'd say it.
- [ ] Settings › Gear: props match what you actually own (Every-day list too).
- [ ] Arena › Day plan: head count, first-timers tick, **Zombie modes today** as you want it, then **Build a full day**. Check it ends with *Dart sweep & teardown* and the sweep sits after block 3.
- [ ] Open the **Packing list** fold, share it to your phone, load the car against it.

## Morning of
- [ ] Arena › Teams: tap everyone who's here into the pool, set blasters, **Draw teams**.
- [ ] Run tab › read the opening talk › **Briefing done**. The first block's rules card opens: read it, tap **Rules read. Start the countdown**.
- [ ] Walk-ins: **+ Walk-in** on the run screen (name, Add).
- [ ] After each round: tap the winner (stat modes: tap tags/outs, then the confirm button). Nothing waits on a timer.
- [ ] Mistakes: Rounds tab › **Edit** on the round.
- [ ] Last item (teardown): tap **Send backup & results to Google Drive** before you leave the field.

## If something goes wrong
- The app won't open: open Chrome, go to https://jlewinfosec.github.io/labl-arena/ and reinstall; Settings › Restore a backup.
- The clock keeps running while locked; unlock with the PIN from the run screen.
- Anything else: note the mode, the round and what you tapped, and bring it to the Phase 3 follow-up session.
